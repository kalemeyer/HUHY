# Security and sensitive-information reporting

Do not open a GitHub issue containing sensitive information.

HUHY accepts publicly released, unclassified information only. Do not submit
PII, PHI, CUI, operational or readiness data, credentials, internal screenshots,
restricted system details, or information whose release status is uncertain.

If you believe sensitive information reached this repository:

1. Do not repeat, quote, download, or redistribute it.
2. Stop related work immediately.
3. Use [GitHub private vulnerability reporting](https://github.com/kalemeyer/HUHY/security/advisories/new)
   for a repository or HUHY website security concern. Do not put sensitive
   government information in GitHub, the HUHY website, Reddit, or chat.
4. Rotate or revoke an exposed credential through its owner immediately.

This repository is not an authorized channel for reporting vulnerabilities in
government systems. Use the affected system owner’s approved disclosure route.

## Supported project surface

Security reports may cover the current `main` branch, the HUHY website, or the
Reddit guide. Include only the minimum public or synthetic reproduction needed.
HUHY will acknowledge a valid project report privately, coordinate a fix, and
publish a security advisory when disclosure is safe and useful.
